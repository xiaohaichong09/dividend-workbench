# 攒股收息 · 退休计划（工作台）

攒股收息记录工具：记录持仓、追踪年度股息目标进度、记录实际到账分红。深色金融界面，电脑手机都能用，手机可像 App 一样装到桌面（PWA）。

## 功能（按示例版）

- **目标卡**：当前年度股息总额、完成百分比、目标金额（可编辑）、进度条、已收 / 成本 / 市值 / 还差
- **持仓卡片**（每只标的两行九项）：收息标的 / 攒股数量 / 当前股价 / 持仓成本 + 近一年每股分红 / 当前股息率 / 成本股息率 / 盈亏比例 / 预计当年分红
- **添加 / 编辑 / 删除**标的：点卡片进入编辑页；输完 6 位代码自动识别名称（股价为空时顺带带出）
- **记收息**：每只标的可记多笔到账分红（日期 + 金额 + 备注），目标卡"已收"按本年合计
- **分红自动取数**：打开标的编辑页（或新增页输完代码）自动拉取分红历史，按**近 12 个月**合计出"每股分红"并填入，明细（除息日 + 方案 + 每股金额）列在下方供人工核对——一年分红一次的自动命中今年或去年那次，一年两次的自动取最近一次 + 上一次；核对无误再点保存。数据来自东方财富分红送配记录。ETF / 场内基金无公开跨域接口，会提示手动填写每份分红。
- **刷新行情**：填 6 位代码（601318 沪 / 000538 深 / 515100 ETF / 北交所 4、8 开头）一键更新股价，数据来自腾讯行情接口
- **同步**：电脑 / 手机通过 WebDAV（推荐坚果云）自动同步；手机安装成 App

> 填分红注意：A 股公告写的是「每10股派 X 元」，工具里填**每股**口径（X ÷ 10）。

## 电脑端使用

双击 `index.html` 用浏览器打开即可（数据存在本机浏览器里）。

## 手机端装成 App

手机浏览器需要 **https 网址**，先把文件部署到静态空间（任选其一）：

| 方式 | 步骤概要 |
| --- | --- |
| GitHub Pages（免费） | 新建仓库 → 上传整个文件夹内容 → Settings → Pages 启用 |
| Cloudflare Pages（免费，国内访问较稳） | 创建 Pages 项目 → 直接上传 `index.html`、`css/`、`js/`、`icons/`、`manifest.webmanifest`、`sw.js` |
| Gitee Pages（国内快） | 需实名认证，传同样文件后开启 Pages |

部署好后手机浏览器打开网址：**安卓** 菜单 →「添加到主屏幕/安装应用」；**iPhone** Safari 分享按钮 →「添加到主屏幕」。

## 电脑 ↔ 手机同步（坚果云 WebDAV）

1. 注册坚果云（jianguoyun.com），网页端新建文件夹如 `dividend`
2. 账户信息 → 安全选项 → **添加应用密码**
3. 工具「设置 → 数据同步」填：地址 `https://dav.jianguoyun.com/dav/dividend/state.json`、账号（邮箱）、应用密码
4. 「保存同步设置」→「立即同步」

两边设备填同一地址即自动互相同步，以最后修改时间为准。

## 常见问题

- **年度股息总额偏大 10 倍？** 公告是「每10股派 X 元」，每股应填 X ÷ 10。
- **刷新行情没反应？** 标的必须填 6 位代码；接口在个别网络环境可能访问不到，手动填股价即可。
- **换浏览器/清了数据，记录没了？** 数据在浏览器本地，换设备前先配置 WebDAV 同步。
- **更新文件后手机还是旧版？** 缓存先开后更，第二次打开即新版。
